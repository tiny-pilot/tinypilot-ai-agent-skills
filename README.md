# TinyPilot AI Agent Skills

**Run AI agents on bare metal.**

This repository contains skills and configurations for using TinyPilot with AI agents such as Claude Code, OpenClaw, Cursor, Codex, and Devin.

TinyPilot enables AI agents to control real systems — including BIOS, boot menus, and operating systems — through keyboard, mouse, and screen access via the TinyPilot API.

---

## Supported Agents

- Claude Code
- OpenClaw
- Cursor
- Codex
- Devin

Each folder contains a version of the TinyPilot skill adapted for that specific environment.

---

## What This Enables

With TinyPilot and an AI agent, you can:

- Interact with systems at the BIOS or boot level  
- Recover machines when the OS is unavailable  
- Automate installation, monitoring, and setup workflows  
- Control remote or headless systems  
- Perform out-of-band troubleshooting  

---

## Getting Started

1. Choose your AI agent (Claude Code, OpenClaw, Cursor, etc.)
2. Download the corresponding skill/configuration from this repository
3. Install it according to your agent’s documentation
4. Connect to your TinyPilot device
5. Start automating

---

## Requirements

- A [TinyPilot device](https://tinypilotkvm.com/products/tinypilot-voyager-3)
- Network access to the device
- A valid [TinyPilot Automation License](https://tinypilotkvm.com/pages/automation) (required for API-based automation)
